# Такс

Прототип для сбора идей, сравнения гипотез и фиксации решений. Для локального запуска откройте `docs/index.html` в браузере. Установка не нужна. SB Sans берётся из установленных шрифтов или официального CDN Plasma.

- Через «Новая гипотеза» добавьте идею с ожидаемой пользой, количеством запросов и оценкой разработки. Если спрос неизвестен, оставьте поле запросов пустым.
- Через кнопку «Важность» выберите уровень для гипотезы. Каталог можно отсортировать по важности, запросам или сроку.
- Выберите до трёх идей кнопкой «Сравнить». Таблица появится ниже плана. Из неё можно добавить гипотезу в план.
- Меняйте доступные дни в блоке «Ресурс». Сохранённое решение можно отредактировать, архивировать, восстановить или удалить из журнала.
- Каталог, оценки ценности, черновик и решения сохраняются в браузере.

Оригинальный логотип экспортирован из предоставленного макета Figma. Проверка логики: `node --test test/board.test.cjs`.

## GitHub Pages

После отправки ветки `main` откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку **main** и папку **/docs**. Ожидаемый адрес после публикации — https://razuv.github.io/taks/.

Данные хранятся в браузере отдельно для каждого домена. Гипотезы и решения из локальной версии или с прежнего адреса автоматически на новый сайт не перенесутся.
